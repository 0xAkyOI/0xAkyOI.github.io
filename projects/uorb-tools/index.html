uORB Tools 是一组轻量级命令行工具，用于在开发 PX4 时快速查看和记录 uORB 消息。

工具#

  • uorb-top：类似 top 的实时消息监视器
  • uorb-dump：将指定 topic 的消息导出为 CSV / JSON
  • uorb-replay：回放录制的日志，辅助离线分析

设计#

所有工具共享一个最小的 uORB 客户端，直接通过共享内存读取消息，无需修改固件。
